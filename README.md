# ATM Management System

A simple ATM Management System developed in Java.

## Features
- User Login
- Balance Enquiry
- Cash Withdrawal
- Cash Deposit
- PIN Verification
- Exit Option

## Technologies Used
- Java
- OOP Concepts

## How to Run

1. Clone the repository

```bash
git clone https://github.com/bv1043842-bhanu/Atm-.git
```

2. Compile the program

```bash
javac Main.java
```

3. Run the program

```bash
java Main
```
